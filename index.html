Two-Phase Microflow Simulator

A phase-field solver for immiscible laminar flow (water and cyclohexane by default) that runs in your browser. You set the geometry, inlet and outlet conditions, fluid properties and wall contact angles, then watch the interface, velocity and pressure fields evolve. It solves the Navier–Stokes equations coupled with a Cahn–Hilliard phase field, so results can be compared directly with phase-field solvers such as COMSOL Multiphysics®.

What the solver does

The two fluids are tracked with a phase-field variable φ: φ = −1 in Fluid 1 (water), φ = +1 in Fluid 2 (cyclohexane), and a smooth tanh profile of thickness ~ε across the interface. The phase field is moved by the flow and relaxes by Cahn–Hilliard diffusion. In return it sets the local density and viscosity and supplies the surface-tension force to the momentum equation. These are the equations, variable names and default parameters COMSOL uses in its Two-Phase Flow, Phase Field interface.

1 · Phase field (Cahn–Hilliard, split into two second-order equations)

∂φ/∂t + u·∇φ = ∇·( (γλ/ε²) ∇ψ )
ψ = −∇·(ε² ∇φ) + (φ² − 1) φ
λ = 3εσ / √8  (mixing energy density),   γ = χ ε²  (mobility; χ is COMSOL's “mobility tuning parameter”)

2 · Laminar flow (incompressible Navier–Stokes, variable properties)

ρ ( ∂u/∂t + (u·∇)u ) = −∇p + ∇·[ μ (∇u + ∇uT) ] + Fst + ρg − (12μ/d²)u[optional Hele-Shaw]
∇·u = 0

3 · The coupling (multiphysics) terms

Vf,2 = (1 + φ)/2,   ρ = ρ1 + (ρ2 − ρ1) Vf,2,   μ = μ1 + (μ2 − μ1) Vf,2
Fst = G ∇φ,   G = λ ψ / ε²  (chemical potential × phase gradient)

So the flow needs φ (for ρ, μ and the capillary force) and the phase field needs u (for advection). That two-way exchange is the entire multiphysics coupling. It is the same thing COMSOL's Two-Phase Flow, Phase Field coupling node does between its Laminar Flow and Phase Field interfaces.

How the equations are solved

A uniform staggered (MAC) grid stores pressure, φ and ψ at cell centres and the velocity components on cell faces, which avoids pressure checkerboarding. The geometry is a cell mask: each cell is fluid or solid, and the cells just outside the domain are tagged as wall, inlet or outlet. The solver never assumes a rectangle, so an imported shape uses exactly the same code path. Each time step:

  1. Update mixture properties ρ(φ), μ(φ) at every cell.
  2. Chemical potential. Compute ψ from the discrete Laplacian of φ. The wetting condition enters as a prescribed flux on wall faces; inlets are Dirichlet. Then set G = λψ/ε².
  3. Advance the phase field with conservative face fluxes: second-order MUSCL (van Leer limiter) advection plus the Cahn–Hilliard flux (γλ/ε²)∇ψ. Because the scheme is written in flux form and the velocity is exactly divergence-free, Fluid 1 is conserved to round-off.
  4. Momentum predictor. An explicit step with advection, the full variable-viscosity stress ∇·[μ(∇u+∇uᵀ)], the capillary force G∇φ evaluated on faces, gravity and the optional Hele-Shaw drag. Pressure is left out of this step.
  5. Pressure projection. Solve a Poisson equation for p so that the corrected velocity is divergence-free. Using the Dodd–Ferrante splitting, the variable-density operator ∇·(1/ρ ∇p) becomes a constant-coefficient Laplacian with a lagged correction. Its matrix never changes, so it is factorised once (banded Cholesky) and each step needs only two triangular solves. That makes the pressure solve direct rather than iterative.
  6. Correct the velocity and record outlet fluxes.

Time step. The scheme is explicit, so Δt is the smallest of the capillary-wave limit √(ρ̄h³/2πσ), the viscous limit ρh²/4μ, the advective limit and the Cahn–Hilliard stability limit, multiplied by a safety factor. The toolbar shows which limit is active. At microscale the capillary limit nearly always controls, and it scales as h1.5, so halving h multiplies the run time by about 11.

Scope and limitations

  • The model is 2D planar, the same as a 2D COMSOL component. Shallow real microchannels are 3D. The optional Hele-Shaw term (channel depth d) adds the depth-averaged wall friction, which is a reasonable first step toward comparison with experiments viewed from above.
  • Time stepping is explicit, so Δt is bounded by capillary waves. COMSOL's implicit BDF solver takes larger steps per solve but does more work per step. Wall-clock times are comparable for small grids.
  • Uniform Cartesian grid. Curved walls from imported CAD are represented as staircases at resolution h.
  • Contact-line motion comes from Cahn–Hilliard diffusion plus Navier slip, as in COMSOL. Dynamic angles therefore depend on χ and β, which is why these two must match when comparing.

Roadmap

  • Geometry import: 2D DXF exported from a COMSOL geometry or a Fusion 360 sketch, rasterised to the cell mask, with inlets and outlets tagged by layer name.
  • COMSOL comparison: load a COMSOL regular-grid export and show difference maps and error norms against this solver at matched times.
  • Experimental validation: overlay measured interface positions or contact angles from microscope images.
  • Performance: move the solver to a Web Worker / WebGPU and add local refinement near the interface.
